## Verdict

The English is clean, plain and close to the consulting register CLAUDE.md asks for. The main weaknesses are a few Polish calques ("workshop"), fragments in the Process sections, and a slogan ("the decisions stay with me") repeated until it sounds like marketing. The factual problem is more serious. Numbers are faithful, but the "What AI did / What I did" columns and the "How I work with AI" section make many process claims that no source supports. In several places, prototypes built for this portfolio are presented as client work Hubert planned (Livingroom states, KSK booking page, "the prototypes on this page were made this way"). One Basko claim is contradicted by Hubert's own screenshot. Since the page sells honesty about the AI/human split, each of these should be confirmed by Hubert or marked as pending before the page is sent.

- English copy quality: **7/10**
- Factual faithfulness: **5/10**
